// Architecture

HOW IT WORKS

Four Splunk AI tools working in a coherent pipeline to watch, detect, and explain agent failures.

01

Instrument Your Agent

OpenTelemetry hooks wrap every LangGraph node — capturing LLM calls, tool invocations, token counts, latency, and errors. Every event flows to Splunk HEC with full structured context.

OpenTelemetry + Splunk HEC
02

Stream to Splunk

Events index in real time via HTTP Event Collector with sourcetype agentwatch:otel. Every reasoning step becomes a searchable, structured log. 1,269+ real events confirmed.

Splunk MCP Server
03

Detect Anomalies

Splunk's native anomalydetection command runs on tool call frequency time-series. Caught a 139-tool-call spike with 99.25% confidence. No manual thresholds needed.

Splunk AI Toolkit — anomalydetection
04

Explain in Plain English

Foundation-Sec-1.1-8B reasons over the anomaly context: what happened, root cause, recommended fix, severity. One click from alert to actionable engineering guidance.

Foundation-Sec-1.1-8B
05

Query with Natural Language

"Show me all loops in the last hour" → auto-generated SPL → results in seconds. No SPL expertise required.

Splunk AI Assistant
// Capabilities

WHAT IT CATCHES

Every failure mode your AI agents can have — detected before it costs you.

🔁

Loop Detection

Catches agents stuck calling the same tool repeatedly. Anomaly fires when call count exceeds threshold — before the API bill arrives.

📈

Token Spikes

Identifies runaway generation — context windows growing unboundedly, prompts accumulating message history without truncation.

🐌

Latency Drift

Detects steps getting progressively slower — the silent performance degradation that's impossible to spot manually.

💀

Silent Failures

Every unhandled exception, every tool error, every confidence collapse — captured with full stack context in Splunk.

🧠

Live Brain Graph

Three.js force-directed visualization shows your agent's reasoning in real time. Green nodes healthy. Red nodes need attention.

🔍

Trust Scoring

Every node gets a trust score (0–100%) based on call patterns, token usage, and error rates. Composite score surfaces risk instantly.
